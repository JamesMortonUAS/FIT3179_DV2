# Vega and Vega-Lite specifications

Save every diagram or map as a separate, formatted JSON file in this folder.
Use the numbered filenames listed in `js/main.js`, then uncomment the matching
entry to embed it on the page.

Each JSON file should include a descriptive `title`, accessible labels,
appropriate tooltips, source information, and a relative data URL such as
`data/global_electricity_2000_2025.csv`.
