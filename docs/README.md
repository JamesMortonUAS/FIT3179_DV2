# Submission document checklist

The assignment requires the approved hand-drawn A4 sketch to remain available at the URL submitted in the assignment template.

Before submission:

1. Scan or photograph the tutor-approved sketch clearly.
2. Save it as `docs/sketch.pdf`.
3. Commit and push it without replacing the hand-drawn content with a digital redraw.
4. Open `https://github.com/JamesMortonUAS/FIT3179_DV2/blob/main/docs/sketch.pdf` in a signed-out window.
5. Put that exact URL in the assignment template.

No sketch has been fabricated or inferred in this repository.
