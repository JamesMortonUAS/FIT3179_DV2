# Data directory

Only place cleaned, web-ready extracts here. Keep total downloadable data below
a few megabytes.

Planned files:

- `global_electricity_2000_2025.csv` — Ember annual country/source data.
- `country_clean_share_latest.csv` — latest country snapshot for maps.
- `country_clean_share_change.csv` — percentage-point change since 2000.
- `australian_state_mix_2000_2025.csv` — Australian Energy Statistics Table O.
- `world-110m.json` — simplified world boundaries.
- `australia-states.topojson` — simplified Australian state boundaries.

Do not publish raw multi-gigabyte or five-minute electricity-market files.
